# Быстрый старт

## Шаг 1: Установка зависимостей
```bash
pip install -r requirements.txt
```

## Шаг 2: Получение токена бота
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и скопируйте полученный токен

## Шаг 3: Настройка токена
1. Откройте файл `.env`
2. Вставьте ваш токен:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```

## Шаг 4: Настройка кнопок (опционально)
Откройте `config.py` и измените кнопки и ссылки по вашему желанию:
```python
BUTTONS = [
    [
        {"text": "🍕 Меню", "url": "https://example.com/menu"},
        {"text": "📍 Адрес", "url": "https://maps.google.com"},
    ],
    [
        {"text": "📞 Контакты", "url": "https://example.com/contacts"},
        {"text": "ℹ️ О нас", "url": "https://example.com/about"},
    ]
]
```

## Шаг 5: Запуск бота
```bash
python bot.py
```

## Готово! 🎉
Теперь откройте вашего бота в Telegram и отправьте команду `/start`
