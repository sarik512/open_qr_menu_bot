# 🤖 Мульти-организационная система ботов

Система для управления несколькими Telegram-ботами через единую админ-панель.

## 📋 Возможности

### Для главного администратора:
- ✅ Создание неограниченного количества организаций
- ✅ Управление кнопками для каждой организации через бота
- ✅ Добавление/редактирование/удаление кнопок без изменения кода
- ✅ Настройка приветственных сообщений для каждой организации
- ✅ Каждая организация работает со своим токеном бота

### Для пользователей:
- ✅ Получают кнопки при команде `/start`
- ✅ Кнопки настраиваются админом через бота

## 🏗️ Структура проекта

```
open_qr_menu_bot/
├── multi_bot.py         # Главный файл (запускает все боты)
├── database.py          # Работа с базой данных SQLite
├── admin_handlers.py    # Обработчики админ-панели
├── config.py            # Настройки (таймауты, прокси и т.д.)
├── bot_data.db          # База данных (создается автоматически)
├── .env                 # Токены и настройки
├── requirements.txt     # Зависимости Python
└── README.md            # Эта инструкция
```

## 🚀 Установка и настройка

### Шаг 1: Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 2: Создайте ботов в Telegram

1. **Создайте админ-бота:**
   - Откройте [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте `/newbot`
   - Укажите название (например: "My Admin Bot")
   - Укажите username (например: "my_admin_bot")
   - Скопируйте полученный токен

2. **Создайте ботов для организаций:**
   - Повторите процесс для каждой организации
   - Или используйте существующий токен

### Шаг 3: Узнайте свой Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID (например: `123456789`)

### Шаг 4: Настройте файл `.env`

Откройте файл `.env` и заполните:

```env
# Токен бота для админ-панели
ADMIN_BOT_TOKEN=ваш_токен_от_BotFather

# Ваш Telegram ID
ADMIN_TELEGRAM_ID=ваш_id_от_userinfobot

# Старый токен (опционально, можно использовать для первой организации)
BOT_TOKEN=существующий_токен
```

**Пример:**
```env
ADMIN_BOT_TOKEN=6234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
ADMIN_TELEGRAM_ID=123456789
BOT_TOKEN=7292276915:AAFg225SgLTzovlckxTl58l4JosLeYMT3AQ
```

### Шаг 5: Запустите систему

```bash
python multi_bot.py
```

Вы должны увидеть:
```
✅ База данных инициализирована
✅ Админ-бот настроен
🚀 Админ-бот запущен
✅ Все боты запущены и работают
```

## 📱 Использование админ-панели

### Открытие админ-панели

1. Откройте вашего админ-бота в Telegram
2. Отправьте команду `/admin`
3. Появится главное меню:

```
🔐 Админ-панель

Выберите действие:
[🏢 Управление организациями]
[🔘 Управление кнопками]
[📊 Статистика]
[❌ Выход]
```

### Создание организации

1. Нажмите **🏢 Управление организациями**
2. Нажмите **➕ Создать организацию**
3. Введите название (например: "New York Burger")
4. Введите токен бота для этой организации
5. Введите приветственное сообщение (или `/skip` чтобы пропустить)
6. ✅ Организация создана!

### Добавление кнопок

1. В меню организаций выберите нужную организацию
2. Нажмите **🔘 Управление кнопками**
3. Нажмите **➕ Добавить кнопку**
4. Введите текст кнопки (например: "Family Park")
5. Введите URL (например: "https://qr.alipos.uz/new-york-burger-family-park")
6. ✅ Кнопка добавлена!

### Редактирование кнопок

1. Выберите организацию
2. **🔘 Управление кнопками** → **✏️ Редактировать кнопку**
3. Выберите кнопку из списка
4. Введите новый текст или URL

### Удаление кнопок

1. Выберите организацию
2. **🔘 Управление кнопками** → **🗑 Удалить кнопку**
3. Выберите кнопку для удаления
4. Подтвердите удаление

## 👥 Работа пользователей

Когда пользователь отправляет `/start` боту организации:
1. Бот показывает приветственное сообщение
2. Отображаются кнопки, настроенные админом
3. При нажатии на кнопку открывается указанная ссылка

## 🗄️ База данных

Система использует SQLite базу данных `bot_data.db` с тремя таблицами:

### Таблица `organizations`
- `id` - ID организации
- `name` - Название
- `bot_token` - Токен бота
- `welcome_message` - Приветственное сообщение
- `created_at` - Дата создания
- `is_active` - Активна ли организация

### Таблица `buttons`
- `id` - ID кнопки
- `organization_id` - К какой организации относится
- `button_text` - Текст кнопки
- `button_url` - URL кнопки
- `row_number` - Номер ряда (0, 1, 2...)
- `position_in_row` - Позиция в ряду (0, 1)
- `created_at` - Дата создания

### Таблица `admins`
- `id` - ID записи
- `telegram_id` - Telegram ID админа
- `username` - Username админа
- `created_at` - Дата добавления

## 🔧 Решение проблем

### Бот не запускается

1. Проверьте правильность токенов в `.env`
2. Проверьте, что указан правильный `ADMIN_TELEGRAM_ID`
3. Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`

### Ошибка 409 (Conflict)

Это означает, что бот уже запущен в другом месте:
1. Остановите все запущенные экземпляры бота
2. Подождите 1-2 минуты
3. Запустите снова

### Админ-панель не открывается

1. Убедитесь, что ваш Telegram ID правильно указан в `.env`
2. Проверьте, что вы отправляете `/admin` именно админ-боту
3. Проверьте логи на наличие ошибок

### Кнопки не отображаются

1. Убедитесь, что кнопки добавлены через админ-панель
2. Проверьте, что организация активна
3. Попробуйте отправить `/start` снова
