# 🤖 Мульти-организационная система ботов

Простая система для управления несколькими Telegram-ботами через одну админ-панель.

## 🎯 Как это работает

1. **Один админ-бот** - вы управляете всем через него (команда `/start`)
2. **Много организаций** - каждая со своим ботом и кнопками
3. **Кнопки настраиваются через бота** - не нужно лезть в код!

## 🚀 Быстрый старт

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Создайте админ-бота
1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Скопируйте токен

### 3. Узнайте свой Telegram ID
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш ID

### 4. Настройте `.env`
```env
ADMIN_BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_TELEGRAM_ID=ваш_telegram_id
```

### 5. Запустите
```bash
python multi_bot.py
```

### 6. Откройте админ-панель
1. Найдите вашего админ-бота в Telegram
2. Отправьте `/start`
3. Готово! 🎉

## 📱 Использование

### Создание организации

1. `/start` → **🏢 Управление организациями**
2. **➕ Создать организацию**
3. Введите название (например: "New York Burger")
4. Введите токен бота (создайте нового бота у @BotFather)
5. Введите приветствие или нажмите **⏭️ Пропустить**
6. ✅ Готово!

### Добавление кнопок

1. Выберите организацию
2. **🔘 Управление кнопками**
3. **➕ Добавить кнопку**
4. Введите текст (например: "Family Park")
5. Введите URL (например: "https://qr.alipos.uz/family-park")
6. ✅ Кнопка добавлена!

### Навигация

На каждом экране есть кнопки:
- **◀️ Назад** - вернуться на предыдущий экран
- **🏠 Главное меню** - вернуться в начало
- **❌ Отмена** - отменить текущее действие

## 🔧 Решение проблем

### Бот не отвечает на /start
- Проверьте правильность токена в `.env`
- Убедитесь, что указан правильный `ADMIN_TELEGRAM_ID`

### Ошибка 409 (Conflict)
- Остановите все запущенные экземпляры бота
- Подождите 1-2 минуты
- Запустите снова

### Не могу вернуться назад
- Теперь на всех экранах есть кнопки навигации!
- Используйте **◀️ Назад** или **🏠 Главное меню**
