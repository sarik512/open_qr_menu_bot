# Telegram Bot с Инлайн Кнопками

**Асинхронный** Telegram бот с 4 инлайн кнопками, которые открывают ссылки при нажатии.

## ⚡ Особенности

- ✅ **Полностью асинхронная архитектура** - эффективная обработка множества пользователей одновременно
- ✅ **Параллельная обработка обновлений** - бот может обрабатывать несколько запросов одновременно
- ✅ **4 инлайн кнопки со ссылками** - автоматическое открытие при нажатии
- ✅ **Логирование** - отслеживание всех действий и ошибок
- ✅ **Обработка ошибок** - корректная обработка исключений
- ✅ **Простая настройка** через .env файл

## 🚀 Быстрый старт


### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
2. Скопируйте полученный токен
3. Создайте файл `.env` на основе `.env.example`:
   ```bash
   copy .env.example .env
   ```
4. Откройте `.env` и вставьте ваш токен:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```

### 3. Запуск бота

```bash
python bot.py
```

## 📝 Настройка кнопок

Чтобы изменить текст и ссылки кнопок, отредактируйте файл `config.py`:

```python
BUTTONS = [
    # Первый ряд кнопок
    [
        {"text": "🍕 Меню", "url": "https://example.com/menu"},
        {"text": "📍 Адрес", "url": "https://maps.google.com"},
    ],
    # Второй ряд кнопок
    [
        {"text": "📞 Контакты", "url": "https://example.com/contacts"},
        {"text": "ℹ️ О нас", "url": "https://example.com/about"},
    ]
]
```

Вы также можете изменить приветственное сообщение:

```python
WELCOME_MESSAGE = "👋 Добро пожаловать, {first_name}!\n\nВыберите интересующий раздел:"
```

## 🚀 Производительность

Бот использует **асинхронную архитектуру** на основе `asyncio`, что позволяет:

- **Обрабатывать тысячи пользователей одновременно** без блокировки
- **Параллельно выполнять запросы** благодаря `concurrent_updates=True`
- **Эффективно использовать ресурсы** сервера
- **Быстро отвечать** на запросы пользователей

### Технические детали:

- Все функции обработчики (`async def`) выполняются асинхронно
- Бот использует event loop для управления конкурентными задачами
- Логирование помогает отслеживать производительность в реальном времени
