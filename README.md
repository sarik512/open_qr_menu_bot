# QR Menu Bot для Telegram

Простой Telegram бот для ресторана New York Burger, который помогает клиентам быстро получить доступ к меню через QR-коды.

## Что делает бот?

Когда пользователь отправляет команду `/start`, бот показывает 4 кнопки с разными филиалами ресторана:
- Family Park
- Sibirskiy  
- Makon mall
- Toyloq

При нажатии на кнопку открывается QR-меню соответствующего филиала.

## Структура проекта

```
open_qr_menu_bot/
├── bot.py              # Основной файл бота (асинхронная логика)
├── config.py           # Настройки кнопок и текстов сообщений
├── requirements.txt    # Зависимости проекта
├── .env                # Токен бота (не загружается в git)
├── .gitignore          # Исключения для git
└── .venv/              # Виртуальное окружение Python
```

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` и добавьте токен бота:
```
BOT_TOKEN=ваш_токен_от_BotFather
```

3. Запустите бота:
```bash
python bot.py
```

## Настройка

Чтобы изменить кнопки или текст приветствия, отредактируйте файл `config.py`.

## Технологии

- Python 3.7+
- python-telegram-bot (асинхронная версия)
- python-dotenv
