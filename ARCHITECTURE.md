# Архитектура бота

## Структура проекта

```
open_qr_menu_bot/
├── bot.py              # Основной файл бота (асинхронная логика)
├── config.py           # Конфигурация кнопок и сообщений
├── .env                # Токен бота (не коммитится в git)
├── .env.example        # Пример файла с токеном
├── requirements.txt    # Зависимости проекта
├── README.md           # Полная документация
├── QUICKSTART.md       # Быстрый старт
└── .gitignore          # Исключения для git
```

## Асинхронная обработка

Бот использует `asyncio` для параллельной обработки запросов:

```
Пользователь 1 ──┐
                 │
Пользователь 2 ──┼──► Event Loop ──► Обработка запросов
                 │                    параллельно
Пользователь 3 ──┘
```

### Преимущества:
- ⚡ Быстрая обработка множества запросов
- 🔄 Неблокирующие операции
- 📊 Эффективное использование ресурсов
- 🚀 Масштабируемость

## Компоненты

### 1. bot.py
- Асинхронные обработчики команд
- Логирование действий
- Обработка ошибок
- Управление жизненным циклом бота

### 2. config.py
- Конфигурация кнопок
- Тексты сообщений
- Настройки логирования

### 3. .env
- Токен бота (секретный)
- Переменные окружения

## Расширение функционала

Для добавления новых команд:

1. Создайте асинхронную функцию в `bot.py`:
```python
async def new_command(update: Update, context: ContextTypes.DEFAULT_TYPE) -> None:
    # Ваш код
    pass
```

2. Зарегистрируйте обработчик:
```python
application.add_handler(CommandHandler("new_command", new_command))
```

3. Добавьте конфигурацию в `config.py` (если нужно)
